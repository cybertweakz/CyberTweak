# CyberTweak
CyberTweak: a modern Windows tweaker and optimizer with a cyber-style GUI. It has 200+ tweaks for performance, gaming, privacy and debloat, each explained in detail, plus one-click installs for 250+ apps via winget and Windows Update profiles. Undo and restore points are built in, and it comes in 6 languages. Run it with one PowerShell command.
